# 网站元数据识别

扫描入口页的标题、favicon 和 ICP 备案信息来自静态 HTTP 响应。入口可包含非根路径或重定向；资源地址依据最终页面 URL 和首个有效的 `<base href>` 解析，规则缓存仍按扫描目标隔离。

## favicon

- 支持属性任意顺序、大小写、单引号、双引号、无引号属性、空白和 HTML 实体。
- 标准 `rel=icon` 优先，其次是触屏及微软图标；没有可用声明时先验证根路径 `/favicon.ico`，再尝试社交图片和图片链接，防止用页面照片替代站点图标。同类 ICO 优先，同级保留文档顺序；查询参数不同的候选分别处理。
- 注释、脚本、文本区和模板内的伪标签不作为资源。`manifest` 与浏览器配置文件不直接作为图片下载。
- 页面最多保留 64 个候选，总共验证最多 8 个。声明候选失败后请求根路径 `/favicon.ico`；没有声明图标时，默认路径允许两次尝试，之后才尝试图片线索。候选验证共享配置的时间预算，取消会终止后续请求；重定向另计实际 HTTP 请求次数。
- PNG、ICO、JPEG、GIF、WebP 和 SVG 可以通过 MIME 或文件签名识别。明确的 HTML 错误页提前结束读取；SVG 要求首个元素为 `svg`，支持跨读取块的长 XML 声明和注释前导。有效 HTTP 图标读取到真实 EOF，没有内容大小上限；超时、提前断流和取消不生成前缀哈希。
- 图标哈希逐块计算，原始块为 1,824 字节，编码块为 2,465 字节，不保留完整图片和完整 Base64 副本。读取完整大图标仍需要相应的网络传输与 CPU 时间。
- `data:image/...` 在 Base64 或百分号解码后，使用与 HTTP 图片相同的字节哈希；解码器不持有完整解码副本。Base64 行宽与最终换行沿用项目哈希约定，同一组原始字节的哈希不变。内联图片只使用完整声明，正文限制内未读到声明结束时不能识别该图片。
- HTTP 资源使用标准库请求构造，保留签名查询串的顺序、转义和连续斜线，并复用引擎连接池、代理、限速、Cookie 和超时设置。
- 同源资源继承自定义请求头；跨源资源和重定向不传递入口自定义认证头。自动 Referer 去除凭据与片段，跨源仅保留源地址，HTTPS 降级不自动发送 Referer。
- 成功哈希属于当前 `HTTPClient`，以 URL、代理、请求头和会话 Cookie 的摘要区分，LRU 按需分配并最多保留 4,096 项。缓存不保存图片、认证头或 Cookie 原文，失败不长期缓存，内联图片不入缓存；关闭 Engine 释放所属缓存。不同 Engine 不共享资源哈希。同一实例中地址和请求上下文未变时，缓存可持续复用到关闭实例或条目被淘汰。

扫描入口页会提取 favicon。其他规则响应仅在根路径 GET 的 HTML 场景提取，避免为每个规则路径重复下载资源。支持 `text/html`、`application/xhtml+xml`；缺失或通用二进制 MIME 时，通过正文判断是否为 HTML。

## ICP 备案信息

- 支持可选省份简称、大小写混合的 ICP、备案或许可证字号、数字、`号` 和网站序号；序号可位于 `号` 前后。
- 数字和字号可以被行内标签、空白或实体分隔；全角字符和常见繁体字号归一化。块级元素会打断未完成的号码，防止跨段拼接。
- 支持 UTF-8、GB18030 和纯文本输入。无候选线索的正文直接返回，识别状态仅保留短候选，返回字段不引用整页正文。
- 优先返回备案官网链接内的有效号码；通过完整主机名判定官网链接。其他场景返回首个有效可见文本候选。
- 注释、脚本、样式、模板和属性中的样例不作为备案信息；仅含“登记号”的文本、缺少字号或数字的字符串、文件路径样例不作为有效候选。

这里只识别页面显示的号码，不验证备案真实性。JavaScript 执行后的内容、未读取到的正文及超出候选或时间预算的资源，需要进一步获取才能确认。

## 开发入口

`finger.GetIconURL` 与 `finger.GetIconURLFromBody` 分别接受字符串与只读字节正文；`finger.ExtractICPRecord` 与 `finger.ExtractICPRecordFromBody` 使用相同识别规则。扫描和 SDK 的正常使用方式不变。

规则中的 `response.icon_hash` 可用于入口页图标匹配。相关行为测试位于 `pkg/finger/metadata_extract_test.go`、`pkg/finger/icon_runtime_test.go`、`pkg/finger/icon_stream_test.go`、`sdk/metadata_integration_test.go` 和 `sdk/instance_isolation_test.go`。

解析语义参考 [HTML 链接规范](https://html.spec.whatwg.org/multipage/links.html#rel-icon)、[data URL 规范](https://www.rfc-editor.org/rfc/rfc2397.html)及 [Go HTML tokenizer](https://pkg.go.dev/golang.org/x/net/html#Tokenizer)。
