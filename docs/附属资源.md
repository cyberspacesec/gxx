# 附属资源

`sdk.WithResources(sdk.ResourceOptions{Robots: true, Sitemap: true})` 在扫描时读取最终页面所在资产的 `/robots.txt` 与 `/sitemap.xml`，写入 `TargetResult.Resources` 与 `BaseInfo.Resources`。默认全关，不发出任何附属资源请求。

```go
type ResourceOptions struct {
    Robots   bool // 读取 /robots.txt
    Sitemap  bool // 读取 /sitemap.xml
    MaxBytes int  // 每个资源保留的正文上限，0 表示 64 KiB
}

type Resource struct {
    Kind       string // robots / sitemap
    URL        string // 跟随同站跳转后的地址
    StatusCode int
    Body       []byte // 正文的前 MaxBytes 字节
    BodyBytes  int64  // 实际读取的正文字节数
    SHA256     string // 实际读取的正文的摘要
    Truncated  bool   // Body 短于实际正文，或正文超过读取上限
}
```

## 请求范围

- 只请求与最终页面**同一资产**（协议、主机、端口，见 [资产与跳转](资产与跳转.md)）的地址。入口 30x 到其他主机时，资源取自跳转后的主机，入口主机不再请求。
- 只跟随指向**同一站点**的 30x，最多 5 跳：主机相同，或两者都是域名且可注册域（eTLD+1）相同；不区分协议与端口。指向其他站点的跳转不访问，结果保留 30x 响应本身。
- 离开请求的源之后只带通用请求头，自定义请求头不发给其他主机。
- 请求经过网络策略（`CheckTarget` 的 `Kind` 为 `resource`）与限速，交换观察器记为 `resource` 记录，与扫描共用 Cookie 会话。
- 请求失败（连接错误、超时、被策略拒绝）的资源不出现在结果中；服务端返回的 404 等响应照常记录状态码与正文。

## 正文

正文按引擎的读取上限读取（默认 512 KiB，`WithBodyLimit` 设置）。`BodyBytes` 与 `SHA256` 覆盖实际读取的全部正文，`Body` 只保留前 `MaxBytes` 字节；`Truncated` 为 `true` 表示 `Body` 短于实际正文，或正文超过读取上限没有读完。
