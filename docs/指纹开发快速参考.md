# GXX 指纹开发快速参考

## 基本模板

### HTTP指纹模板

```yaml
id: 指纹ID

info:
  name: 指纹名称
  author: 作者
  verified: false
  description: 描述文本
  reference:
    - 参考链接
  tags: tag1,tag2
  created: 2025/04/01

rules:
  r0:
    request:
      method: GET
      path: /
     expression: response.status == 200 && response.body.ibcontains(b"特征字符串")

expression: r0()
```

### TCP指纹模板

```yaml
id: 指纹ID

info:
  name: 指纹名称
  author: 作者
  verified: false
  description: 描述文本
  tags: tcp,network
  created: 2025/04/01

set:
  hostname: request.url.host

rules:
  r0:
    request:
      type: tcp
      host: "{{hostname}}"
      data: "test\n"
    expression: response.raw.bcontains(b"服务特征")

expression: r0()
```

### UDP指纹模板

```yaml
id: 指纹ID

info:
  name: 指纹名称
  author: 作者
  verified: false
  description: 描述文本
  tags: udp,network
  created: 2025/04/01

set:
  hostname: request.url.host

rules:
  r0:
    request:
      type: udp
      host: "{{hostname}}:53"
      data: "\n"
    expression: response.raw.bcontains(b"服务特征")

expression: r0()
```

## 常用表达式

### HTTP表达式

- `response.status == 200`
- `response.body.bcontains(b"特征字符串")` - 响应体包含特定二进制字符串（区分大小写）
- `response.body.ibcontains(b"特征字符串")` - 响应体包含特定二进制字符串（不区分大小写）
- `response.headers["Server"] == "Apache"`
- `response.headers["Content-Type"].contains("json")`
- `response.raw_header.bcontains(b"Server: Apache")` - 原始响应头包含特定字符串
- `response.raw_header.ibcontains(b"server: apache")` - 原始响应头包含特定字符串（不区分大小写）
- `response.body.bmatches(b"正则表达式")`
- `response.icon_hash == "图标哈希值"`

### TCP/UDP表达式

- `response.raw.bcontains(b"服务特征")` - 原始响应包含特定二进制字符串（区分大小写）
- `response.raw.ibcontains(b"服务特征")` - 原始响应包含特定二进制字符串（不区分大小写）
- `response.raw.bmatches(b"正则表达式")`

## 常用函数

> 以下是当前 CEL 引擎实际暴露的全部函数（来自 `pkg/cel/celprogram.go`）。
> 编写规则时请严格按本表使用，未列出的函数（如 `sha1` / `randomAlpha` 等）在 GXX 中不存在。

### 随机函数

- `randomInt(min, max)` — 返回 `[min, max)` 之间的随机整数
- `randomLowercase(n)` — 返回长度为 `n` 的随机小写字母字符串

### 编码 / 哈希函数

- `base64(s)` / `base64(b)` — Base64 编码，入参可为 string 或 bytes
- `base64Decode(s)` / `base64Decode(b)` — Base64 解码
- `md5(s)` — 返回 32 位十六进制 MD5 字符串
- `urlencode(s)` / `urlencode(b)` — URL 编码（`url.QueryEscape`）
- `urldecode(s)` / `urldecode(b)` — URL 解码（`url.QueryUnescape`）
- `hexdecode(s)` — 十六进制串解码为字符串
- `faviconHash(s)` / `faviconHash(b)` — 计算 favicon 内容的 mmh3 哈希（int64）

### 字符串处理函数

- `icontains(s, sub)` (string member) — 字符串包含，不区分大小写
- `substr(s, start, length)` — 截取 `[start, start+length)` 区间的子串
- `replaceAll(s, old, new)` — 全部替换
- `printable(s)` — 仅保留可打印 Unicode 字符
- `toUintString(s, direction)` — 把数字字符串规范化为 uint 形态，`direction == "<"` 时先反转字符串

### 字节匹配函数

- `bcontains(b)` (bytes member) — 字节包含，区分大小写
- `ibcontains(b)` (bytes member) — 字节包含，不区分大小写（**推荐**）
- `bstartsWith(b)` (bytes member) — 字节前缀匹配

### 正则函数

- `bmatches(pattern, b)` (string member) — 正则匹配字节流，返回 bool
- `submatch(pattern, s)` (string member) — 命名捕获字符串，返回 `map[string]string`
- `bsubmatch(pattern, b)` (string member) — 命名捕获字节流，返回 `map[string]string`

> 正则引擎为 `dlclark/regexp2`（兼容 .NET 风格），支持命名捕获 `(?<name>...)`、零宽断言等。

### 时间函数（无参占位 `0`）

- `year(0)` — 当前年份 4 位（如 `"2026"`）
- `shortyear(0)` — 当前年份 2 位（如 `"26"`）
- `month(0)` — 当前月份 2 位（如 `"05"`）
- `day(0)` — 当前日期 2 位（如 `"22"`）
- `timestamp_second(0)` — 当前 Unix 时间戳（秒，字符串形态）

### 流程控制 / 杂项

- `sleep(seconds)` — 阻塞指定秒数（CEL 表达式中谨慎使用）

## 变量引用

### 语法
```
{{变量名}}
```

> `{{}}` 替换在 `path` / `body` / `host` / `data` / `raw` 等字符串字段中生效；
> 对于 `*proto.Request / Response / UrlType` 等结构体对象不做替换，避免触发昂贵的序列化。

### set 块语法

```yaml
set:
  # 值是 CEL 表达式，求值结果赋给变量
  num: randomInt(800000000, 1000000000)
  payload: randomLowercase(20)
  hostname: request.url.host
```

### 示例

- `path: "/{{num}}.php"`
- `host: "{{hostname}}:22"`
- `data: "{{payload}}"`

## payloads（多组特征探测）

`payloads` 用于在同一指纹下并行尝试多组变量，常见用法是同一 CMS / 框架在不同版本部署中后台路径不同，通过多组路径 + 关键字提高识别覆盖率：

```yaml
payloads:
  continue: true       # true=命中后继续跑下一组；false=命中即停
  payloads:
    set1:
      path: "/admin/login"
      keyword: "管理后台登录"
    set2:
      path: "/manage/login.html"
      keyword: "后台管理系统"

rules:
  r0:
    request:
      path: "{{path}}"
    expression: response.status == 200 && response.body.ibcontains(bytes(keyword))
expression: r0()
```

- **与**: `条件1 && 条件2`
- **或**: `条件1 || 条件2`

## HTTP请求参数

- `method`: GET/POST/PUT/DELETE...
- `path`: 请求路径
- `headers`: 请求头
- `body`: 请求体
- `follow_redirects`: 是否跟随重定向

## 请求 / 响应对象属性

### request（proto.Request）

- `request.url.{scheme,domain,host,port,path,query,fragment}` — URL 拆解字段
- `request.method` — HTTP 方法
- `request.headers` — 请求头（map[string]string，key 小写）
- `request.content_type` — `Content-Type` 头快捷字段
- `request.body` — 请求体（bytes）
- `request.raw` — 完整原始请求报文（bytes）
- `request.raw_header` — 原始请求头（bytes）

### response（proto.Response）—— HTTP

- `response.status` — HTTP 状态码（int32）
- `response.url.{scheme,domain,host,port,path,query,fragment}` — 实际响应 URL（可能经重定向）
- `response.headers` — 响应头（map[string]string）
- `response.content_type` — `Content-Type` 头快捷字段
- `response.body` — 响应体（bytes）
- `response.raw` — 完整原始响应（bytes）
- `response.raw_header` — 原始响应头（bytes）
- `response.icon_hash` — favicon mmh3 哈希（扫描入口页，或根路径 GET 的 HTML 响应；详见 [网站元数据识别](网站元数据识别.md)）
- `response.latency` — 响应延迟（int，单位毫秒）

### response —— TCP / UDP / Raw

- `response.raw` — 原始响应字节流

## 匹配函数对比

| 函数 | 区分大小写 | 接收者 | 入参 | 说明 |
|-----|----------|--------|------|------|
| `bcontains(b)` | ✅ | bytes | bytes | 字节包含 |
| `ibcontains(b)` | ❌ | bytes | bytes | 字节包含（**推荐**） |
| `bstartsWith(b)` | ✅ | bytes | bytes | 字节前缀 |
| `contains(s)` | ✅ | string | string | CEL 内置，针对 headers/string 字段 |
| `icontains(s)` | ❌ | string | string | 字符串包含 |
| `bmatches(b)` | 由正则决定 | string(pattern) | bytes | 正则匹配，返回 bool |
| `submatch(s)` | 由正则决定 | string(pattern) | string | 命名捕获，返回 map |
| `bsubmatch(b)` | 由正则决定 | string(pattern) | bytes | 命名捕获，返回 map |

## 常见问题

### 请求失败

- 检查目标是否可访问
- 检查请求参数是否正确
- 检查网络代理设置

### 匹配失败

- 使用 `--debug` 模式查看响应详情
- 确认特征字符串是否存在
- 注意 `response.headers` 的 key 已统一为**小写**：取 Server 应写 `response.headers["server"]`
- 优先用 `response.raw_header.ibcontains(b"...")` 做字节匹配，规避大小写问题
- 字节字段（`body` / `raw` / `raw_header`）必须配字节方法（`bcontains` / `ibcontains` / `bmatches`），不能用 `contains` 这类字符串方法

### 变量引用错误

- 确保变量名正确
- 确保在 `set` 中定义了变量
- 正确使用 `{{变量名}}` 语法

### CEL 函数不存在

如下函数在 GXX 中**未实现**，请勿在规则中使用：

- ❌ `sha1` / `sha256`（仅支持 `md5`）
- ❌ `randomUppercase` / `randomAlpha` / `randomNumber`（仅支持 `randomLowercase`）

如确需，可在 `pkg/cel/celprogram.go` 中按相同模板自行扩展。

## 命令行工具

### 测试单个目标

```bash
gxx -u https://example.com -p path/to/fingerYaml.yml
```

### 测试所有指纹

```bash
gxx -u https://example.com -pf path/to/fingerYaml/dir
```

### 开启调试模式

```bash
gxx -u https://example.com -p path/to/fingerYaml.yml --debug
```
